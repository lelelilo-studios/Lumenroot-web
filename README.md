# LUMENROOT (web build)

Playable web build of **LUMENROOT**, currently the *Echo Garden* M1 prototype.

**Play:** https://lelelilo-studios.github.io/Lumenroot-web/

Controls: WASD to walk · hold right mouse or K to raise the Echo Lantern · E at a sconce to hang or take the lantern · Space to roll · F1 hides the notes.

Build: v0.19.0

This repo only holds the exported build. It's generated from the main project with
`godot --headless --export-release "Web" <this folder>/index.html`.
